# Lennokkikilpailut – järjestäjän hallintasivu

Käyttöliittymän ensimmäinen luonnos (0.1).

## Tiedostot
- `index.html` – sivun rakenne
- `style.css` – ulkoasu ja mobiilinäkymä
- `app.js` – sivuvalikon toiminta

## Käynnistäminen
Avaa `index.html` selaimessa tai julkaise tiedostot GitHub Pagesissa.

## Tärkeää
Tiedot ovat tässä vaiheessa staattisia esimerkkitietoja. Sivua ei ole vielä yhdistetty Google Sheetsiin eikä Apps Scriptiin. Rajapinta ja käyttöoikeuksien tarkistus toteutetaan myöhemmin Apps Scriptin puolella.

Pisteytyksen nykyiseen Apps Script -logiikkaan ei tehdä muutoksia tämän luonnoksen yhteydessä.

## GitHub
Lisää nämä neljä tiedostoa frontendin GitHub-repositorion juureen tai omaan kansioonsa. Pidä `index.html`, `style.css` ja `app.js` samassa kansiossa.
